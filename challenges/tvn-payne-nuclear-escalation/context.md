# Context — TVN-Payne Nuclear Escalation

## Upstream Edges

None. This was the first challenge and established the foundational constraint mapping.

## Downstream Edges

### → Agents of Chaos (VALIDATED)
**Edge type:** Scale invariance
**Hypothesis:** The same archetypes that catch nuclear escalation catch social engineering because psychological failure patterns are scale-invariant.
**Status:** CONFIRMED. The same 14-archetype vocabulary produces enforcement convergence on both nuclear (7 scenarios) and social engineering (11 scenarios) failure modes. Five archetypes fire across both challenge domains: `cautionary_fall`, `cunning_triumph`, `greed_backfire`, `empire_cycle`, `catastrophe_rebuild`.

### → UAT-8616 selfcheck-core (HYPOTHESIS)
**Edge type:** Infrastructure pattern sharing
**Hypothesis:** Infrastructure compromise campaigns share `cunning_triumph` (stealth normalization, firmware rollback) and `empire_cycle` (infrastructure control, sovereignty over network fabric) archetype patterns with nuclear escalation scenarios.
**Status:** UNTESTED. The TVN lens framework was adapted for selfcheck-core's strategic framework, but no constraint harness has been built to validate archetype activation on infrastructure forensic scenarios.

## Known Gaps

- **L1 (Semantic Coherence) and L2 (Lexical Density):** Do not fire on 2 scenarios — these are correct detection boundaries where focused attacks produce insufficient lexical density for these particular lenses.
- **Nuclear-specific context:** The harness tests archetype detection, not nuclear domain knowledge. A model that correctly identifies `cunning_triumph` patterns does not necessarily understand nuclear doctrine.
